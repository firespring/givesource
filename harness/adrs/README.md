# Architecture Decision Records (ADRs)

Record significant architectural decisions with context and consequences. ADRs are immutable once accepted; supersede via a new ADR that references the old one.

- Filename format: `adr-XXXX-title.md` (zero-padded sequence).
- Status values: Proposed | Accepted | Superseded | Rejected | Deprecated.
- Keep them concise; link to code, plans, and amendments where relevant.

Template: see `adr-0000-template.md`.
