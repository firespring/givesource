# Amendments (Append-only)

Use amendments to record scope, timeline, or approach changes to an active plan.

- Filename format: `YYYYMMDD-HHMM-<plan-slug>-amendment.md` (UTC timestamp).
- Once written, do not edit; create a new amendment if needed.
- Include: reason, impact, new scope, and links to affected plan/ADRs/PRs.
